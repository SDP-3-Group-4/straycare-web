## 🌟 About StrayCare

StrayCare is a modern web application built to connect communities to save stray animals. It provides features for users to report stray animals in need, share adoption posts, and build a network of animal lovers and rescuers.

## ✨ Key Features

- **User Authentication**: Secure signup and login flow.
- **Animal Reporting**: Report stray animals that need medical attention or rescue.
- **Community Feed**: View, like, and interact with community posts and reports.
- **User Profiles**: Manage your own profile, rescue history, and posts.
- **Responsive Design**: Beautiful, modern UI that works flawlessly on desktop and mobile.

## 🚀 Technologies Used

- **Frontend Framework**: React
- **Language**: TypeScript
- **Styling**: Modern CSS
- **Authentication**: Context/Firebase
- **Backend/API**: Node.js & Prisma (in `straycare-backend`)
